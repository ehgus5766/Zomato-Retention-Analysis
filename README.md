# ZOMATO 고객 이탈 예측 및 고객 세분화

ZOMATO 주문 데이터를 이용해 고객 이탈을 예측하고, 고객 행동을 기준으로 세분화한 프로젝트입니다.

처음에는 이탈 가능성이 높은 고객을 예측하는 것을 목표로 했습니다.
모델을 만들면서 시간 순서를 고려하지 않은 데이터 분할에서 데이터 누수를 확인했고,
시간 순서에 맞춰 다시 나눈 뒤에는 클래스 불균형이 크게 나타났습니다.

이탈 기준을 여러 방식으로 바꾸고 학습 데이터 보강도 시도했지만,
현재 데이터에서는 이탈 예측보다 매출에 기여하는 고객을 찾는 쪽이 더 의미 있다고 판단했습니다.

그래서 분석 방향을 고객 이탈 예측에서 고객 행동 기반 세분화로 변경했습니다.

## 데이터 전처리

주문, 사용자, 레스토랑 데이터를 결합하고 고객 행동 변수를 생성해 분석용 데이터셋을 만들었습니다.

`sales_qty`, `sales_amount`, `cost`의 분포를 확인한 뒤
로그 변환과 IQR 기준 이상치 처리를 진행했습니다.

- 원본 데이터: 255,576건
- IQR 기준 제거된 이상치: 39,375건
- 이상치 처리 후: 216,201건

이후 고객별 주문 횟수, 구매 금액, 이용 기간, 최근 주문일 등을 계산해
모델링과 군집화에 사용할 변수를 만들었습니다.

## 고객 이탈 예측

처음에는 고객의 행동 데이터를 이용해 이탈 여부를 예측했습니다.

사용한 모델은 다음과 같습니다.

- RandomForest
- XGBoost
- PyTorch 기반 MLP

모델보다 먼저 문제가 됐던 것은 이탈 기준이었습니다.

처음 기준에서는 한 번만 주문한 고객도 이탈자로 포함됐고,
기준을 바꾸면 반대로 이탈자가 지나치게 적어지는 경우가 있었습니다.
시간 순서를 고려하지 않은 분할에서는 데이터 누수도 확인됐습니다.

이 때문에 이탈 기준을 총 5가지 방식으로 바꿔가며 확인했습니다.

시간 순서대로 학습 데이터와 검증 데이터를 나누자
일부 검증 구간에는 이탈 고객이 거의 없거나 아예 없는 경우도 있었습니다.

학습 데이터에서는 SMOTE와 CTGAN을 활용한 데이터 보강을 시도했습니다.
다만 검증 데이터까지 인위적으로 늘리면 실제 성능을 확인하기 어렵기 때문에
검증 데이터는 그대로 두었습니다.

그 결과 학습 데이터는 보강할 수 있었지만,
시간 순서로 나눈 검증 데이터의 클래스 불균형 문제는 계속 남았습니다.

## 분석 방향 변경

이탈 예측을 계속 진행하기보다 EDA 결과를 다시 확인했습니다.

고객의 이용 금액은 늘고 있었지만 주문 횟수는 줄고 있었고,
전체 매출도 감소하는 흐름을 보였습니다.

특히 상위 3% 고객이 전체 매출의 약 15%를 차지하고 있었습니다.

이 결과를 보고 분석 질문을 바꿨습니다.

> 누가 이탈하는가?

에서

> 누가 매출에 기여하는가?

로 방향을 변경했습니다.

이탈 여부 하나를 예측하는 것보다
실제 구매 행동에 따라 고객을 나누고 각 그룹의 특징을 확인하는 쪽으로 진행했습니다.

---

## 고객 군집화

구매 금액, 주문 횟수, 이용 기간, 최근 주문일 등
고객 행동 데이터를 이용해 K-Means 군집화를 진행했습니다.

주요 변수는 다음과 같습니다.

- `total_sales_amount`
- `total_order_count`
- `avg_order_amount`
- `avg_quantity_per_order`
- `total_quantity`
- `active_days`
- `days_since_last_order`
- `order_frequency`
- `monetary_per_day`
- `recency_ratio`
- `avg_days_between_orders`

변수의 단위와 이상치 영향을 줄이기 위해 RobustScaler를 사용했습니다.

고객은 최종적으로 3개 군집으로 나눴습니다.

| 평가 지표 | 결과 |
| --- | ---: |
| Silhouette Score | 0.8809 |
| Davies-Bouldin Score | 0.4931 |
| Cluster | 3개 |

군집별 구매 금액, 주문 횟수, 활동 기간 등을 비교해
고객군마다 어떤 차이가 있는지 확인했습니다.

---

## Tableau

군집 결과를 기존 데이터에 다시 붙여 Tableau에서 분석했습니다.

1차 EDA에서는 개별 조건을 중심으로 봤다면,
군집화 이후에는 고객군과 구매 행동을 함께 볼 수 있도록 구성했습니다.

고객군별 구매 금액, 주문 횟수, 이용 기간, 최근 주문일 등을 비교해
고빈도·고액 고객군을 확인하는 데 사용했습니다.

## 담당한 부분

프로젝트에서는 모델 설계와 구현을 중심으로 작업했습니다.

- 데이터 전처리 및 고객 행동 변수 생성
- 이탈 기준 5가지 방식 비교
- RandomForest, XGBoost, MLP 모델 비교
- PyTorch 기반 MLP 구현
- SMOTE, CTGAN을 이용한 소수 클래스 보강 실험
- SHAP을 이용한 변수 영향 확인
- K-Means 고객 군집화
- 군집 평가 및 분석 결과 정리

## 아쉬웠던 점

이 프로젝트에서는 모델 성능을 높이는 것보다
데이터를 어떻게 나누고 이탈을 어떻게 정의하는지가 더 큰 문제였습니다.

특히 시간 순서로 데이터를 나눴을 때 클래스 불균형이 심했고,
학습 데이터를 보강하더라도 실제 검증 데이터의 분포까지 바꿀 수는 없었습니다.

또 고객의 연령, 직업, 소득 분포가 일부 구간에 몰려 있어
군집별 차이를 더 세밀하게 나누는 데도 한계가 있었습니다.

RFM과 비슷한 변수를 만들어 사용했지만
RFM 분석 자체를 별도로 구성하지 못한 점도 아쉬웠습니다.

추가로 진행한다면 RFM 기준의 고객 세분화와
현재 K-Means 결과를 비교해보고 싶습니다.
